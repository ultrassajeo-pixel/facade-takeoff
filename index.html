AI 대화 연결

기본 연결은 이 Mac에 로그인된 ChatGPT 계정입니다. 구독의 Work·Codex 한도를 사용하며 별도 API 키는 필요 없습니다.

ChatGPT 로그인 상태를 확인합니다.

ChatGPT 연결은 공식 Codex 로그인을 사용합니다. 대화·도면 해석 요약·추출 문자·문서 텍스트를 전송하며 DWG 원본은 보내지 않습니다. 구독 한도나 계정의 크레딧 설정이 적용됩니다. 한도 소진 시 별도 유료 API로 자동 전환하지 않습니다. API 키는 별도 API 방식을 직접 선택한 경우에만 사용하며 화면 메모리에만 유지합니다.
