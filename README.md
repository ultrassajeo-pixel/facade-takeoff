# 외벽산출 · 도면 작업실 v0.6.2

DWG와 외부참조를 읽고, 필요한 시공 조건을 확인한 뒤 판넬·볼트·후레싱·피스·실리콘을 계산하는 Mac 로컬 웹앱입니다. 노무비·장비비는 제외합니다.

## 자신의 Codex에서 사용하기

1. GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. 자신의 ChatGPT 계정으로 사용하는 Codex에서 이 폴더를 엽니다.
3. 다음과 같이 요청합니다.

> AGENTS.md와 README.md를 읽고 필요한 실행 환경을 확인해줘. 프로그램을 실행하고, 내가 제공한 DWG와 외부참조 파일로 물량 산출을 진행해줘. 도면과 기존 조건에서 먼저 정보를 찾고, 수량에 영향을 주는 미정 사항만 질문해줘. 불명확한 형상이나 조건은 임의로 보정하지 마.

AI 대화는 받는 사람 자신의 계정에서 진행하고, 수량은 이 프로그램의 계산 엔진으로 계산합니다. 계정·로그인 토큰·API 키는 배포에 포함하지 않습니다. 일반 ChatGPT에 소스만 첨부하는 방식과는 다르며, 로컬 파일 접근·프로그램 실행이 가능한 환경이 필요합니다.

## 실행

검증된 환경은 **macOS, Node.js 22 이상, Python 3**입니다. Windows 실행은 검증하지 않았습니다.

```sh
python3 bootstrap.py
npm test
npm start
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. Mac에서는 `zsh start.command`로 Safari까지 열 수 있습니다. 최초 실행은 고정 버전의 DWG/PDF 엔진을 내려받아 SHA-512로 검증합니다. `npm install`은 필요하지 않습니다. DWG 판독·계산은 준비 후 오프라인으로 사용할 수 있습니다.

8765에서 이전 버전이 실행 중이면 먼저 그 서버를 종료하세요. 실행 도구는 기존 작업실이 있으면 그 주소를 다시 엽니다. 업데이트는 기존 폴더를 덮어쓰기보다 새 폴더에 받고, 저장한 프로젝트를 새 버전에서 복원하세요. 원본 DWG와 프로젝트 저장 파일은 소스 폴더 밖에 보관하세요.

## 도면과 산출

- 주도면과 참조 DWG를 함께 선택하거나 도면 폴더를 엽니다. 누락된 참조는 추가할 수 있습니다.
- 일반 2D XCLIP은 실제 표시 영역을 계산하고 가상 절단 경계에 새 후레싱·코킹을 만들지 않습니다.
- 열린 직선은 같은 출처·평면 안에서 닫힌 영역을 복원합니다. **복원 영역 개수는 판넬 장수가 아닙니다.**
- 단위·제품·방향·하지·후레싱·방수 조건 중 필요한 값을 확정한 후 계산합니다. CSV·산출서 HTML·프로젝트 JSON/gzip을 저장할 수 있습니다.
- 현재 작업을 Codex에 전달하려면 앱의 **현재 작업 전달**을 누른 뒤 `.runtime/current-project.json`을 읽도록 요청합니다. 이 파일은 로컬 전용이며 Git에 올리지 않습니다.
- 기준값과 구현 정책은 `config/common-rules.json` 및 `docs/산출규칙.md`를 참고합니다. 현장 조건과 샘플 시험 조건을 혼동하지 않습니다.

## 앱 내부 AI 대화는 선택 사항

Codex에서 직접 대화하며 사용하는 방식은 앱 내부 AI 연결이 필수가 아닙니다. 앱 내부 대화를 쓰려면 받는 사람의 Mac에 공식 Codex가 설치되고 그 사람의 ChatGPT 계정으로 로그인되어 있어야 합니다. `connect-chatgpt.command`로 로그인하고 앱의 AI 연결 설정에서 상태를 확인합니다.

로그인 처리는 공식 CLI가 담당하며 인증 파일을 읽거나 배포하지 않습니다. 구독 연결 실패 시 유료 API로 자동 전환하지 않습니다. 코드에는 별도 선택형 API/Ollama 연결도 있지만 이 배포의 필수 조건이 아닙니다. CLI 버전에 따라 앱 내부 연결 호환성을 확인해야 합니다.

## 확인된 범위와 한계

v0.6.2 자동 테스트 133개 통과. 실제 브라우저에서 가상 12m×6m 샘플의 판독·산출표 발행을 확인했습니다. 샘플 가상 조건의 순면적은 65.52m²이며 판넬 13장, 후레싱 28본, 볼트 100개, 피스 300개, 실리콘 14통입니다. 예비분·포장·실리콘 체적 조건이 포함된 **시험용 결과**로, 실제 현장 수량이나 공통 기본값이 아닙니다.

실제 현장 도면에서 개별 판넬을 모두 인식하거나 오류 없는 물량을 보장하는 단계는 아닙니다. 가림막(WIPEOUT), 비평면·불명확한 경계, 미확정 상세 및 시공 조건은 산출을 보류할 수 있습니다. 99% 정확도는 측정 성과가 아닙니다. 테스트를 통과했다는 이유로 차단을 해제하거나 수량을 추정해서 발행하지 않습니다.
