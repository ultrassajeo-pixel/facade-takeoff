# 공통 산출 규칙

구현: `config/common-rules.json`, `src/common-rules.mjs`, `src/takeoff.mjs`

출처는 2026-11-15 사용자와의 대화다. 아래 **사용자 확정 규칙**과 **구현상 계산 정책**은 구별한다.

## 사용자 확정 규칙

| ID | 항목 | 합의 내용 |
|---|---|---|
| P01 | 제품·규격 | 제품, 두께, 유효폭은 현장마다 다르다. 공통 고정값을 두지 않는다. |
| P02 | 시공 방향 | 현장·도면마다 결정한다. 외벽은 가로가 많고 세로도 있으며, 내벽은 주로 세로라는 경향만 기록한다. 경향을 확정 입력으로 쓰지 않는다. |
| P03 | 개구부 처리 | 개구부를 반영해 필요한 판넬 조각별 길이를 산출한다. |
| P04 | 최소 제작 길이 | 발주 판넬 한 장의 최소 길이는 **3,000mm**. 짧은 조각은 다른 조각과 합쳐 최소 길이를 충족한다. |
| P05 | 최대 제작 길이 | 발주 판넬 한 장의 최대 길이는 **13,000mm**. |
| P06 | 합산 대상 | 같은 규격이면 긴 조각과 짧은 조각을 함께 묶어 발주할 수 있다. 짧은 조각끼리만 묶도록 제한하지 않는다. |
| P07 | 발주 길이 합산 | 조각 길이를 더할 때 별도의 절단 여유를 가산하지 않는다. 500mm 두 조각의 합산 길이는 1,000mm다. 다만 이 합계가 최소 3m 미만이면 다른 조각과 더 묶어야 한다. |
| P08 | 남는 길이 | 같은 규격의 필요한 조각을 모두 합쳐도 3m 미만이면 3m로 주문하며, 남는 길이는 잔재로 처리한다. |
| B01 | 주고정 볼트 | 판넬 한 장과 하지 한 줄이 만나는 곳마다 **1개**. 일반 끝단·중간을 구분한 별도 개수는 주지 않았다. |
| F01 | 후레싱 정척 | **3,000mm/본**으로 발주한다. |
| F02 | 후레싱 겹침 | 연결부를 **30~50mm** 겹친다. 사용자 확정값은 범위이며 단일 50mm가 아니다. |
| S01 | 후레싱 피스 | **300mm 간격, 두 줄** 고정한다. |
| C01 | 코킹 대상 | 판넬과 판넬의 이음, 창호와 판넬 접합, 후레싱 양쪽 측면 등 빗물 유입을 막아야 하는 부위. 모든 도면 선을 코킹선으로 보지 않는다. |
| C02 | 실리콘 소요량 | 한 통으로 **약 2.5m** 시공한다. |

## 발주 예시

- 같은 규격의 4,000mm 두 조각과 500mm 두 조각은 **4,500mm 두 장**으로 발주할 수 있다. 현장에서 각각 4,000mm와 500mm로 나눈다.
- 500 + 500 + 2,000mm 조각은 **3,000mm 한 장**으로 발주하고 설치 조각은 3개로 구분한다.
- 총 필요한 길이가 1,000mm뿐이라면 **3,000mm 한 장**을 발주하고 길이 차이 2,000mm는 잔재다.

발주 장수와 설치 조각 수는 같은 값이 아니다. 각 발주 판넬에 어떤 조각이 들어가는지 절단 구성을 보존한다. P07은 발주 길이 산정 관행이며 실제 톱날 절단폭이 물리적으로 0이라는 의미는 아니다.

## 기본 산식

- 볼트: 실제 하지와 판넬의 유효 교차 구간 수 × 1개. 존재하지 않는 하지나 보강을 임의로 추가하지 않는다.
- 후레싱: 정척·적용 겹침을 이용해 각 설치 구간을 덮는 제작 본수를 계산한다.
- 실리콘: `ceil(중복 제거한 실제 코킹 길이(m) / 2.5)` 통. 이 값은 사용자가 제시한 현장 소요량 기준이며 제품별 실측 수율을 보증하지 않는다.

## 구현상 계산 정책 — 사용자 답변과 구별

아래는 규칙을 수식으로 옮길 때 프로그램이 표시하는 정책이다. 사용자 확정 발언으로 바꿔 기록하지 않는다.

| 항목 | 프로그램 정책 / 주의점 |
|---|---|
| 후레싱 범위 처리 | 별도 확정값이 없는 경우 발주 산정에 범위 상단 50mm를 사용하는 정책을 표시한다. 원래 합의 범위 30~50mm는 보존한다. 실제 겹침이 항상 50mm라고 표시하지 않는다. |
| 피스 위치 산정 | 연속 설치 구간의 양끝을 포함하고 최대 간격 300mm를 넘지 않게 배치하는 산식. 겹침부 추가 피스가 도면에 있으면 별도로 반영해야 한다. |
| 예비분·판매 포장 | 사용자와 별도 예비율·포장 수량을 합의하지 않았다. 기본 필요량에 임의 비율을 가산하거나 묶음 포장을 가정하지 않는다. 산출서에 미반영 사실을 표시한다. |
| 합산 최적화 | 필요한 조각 길이를 보존하면서 총 발주 재료 길이를 줄인다. 계산 한도 내에서 재료 길이 최소를 확정하지 못하면 확정 수량 발행을 보류한다. 최저 발주 장수까지 항상 보장한다고 주장하지 않는다. |
| 코킹 중복 | 같은 물리적 코킹선만 중복 제거한다. 창호 접합과 후레싱 측면이 같은 선인지 다른 면인지 불명확하면 상세 근거가 필요하다. 두 줄 코킹을 한 줄로 합치지 않는다. |

## 현장마다 확인할 정보

- 판넬 제품·두께·색상 등 합산 가능한 동일 규격 구분, 유효폭·발주 폭, 실제 시공 방향
- 산출할 입면과 형상, 도면 단위, 개구부와 판넬 배치, 길이 방향 이음 위치
- 하지 간격·실제 위치·시작점과 끝단 또는 이음부의 실제 보강 여부
- 설치할 후레싱 부위·형상·전개폭·미설치 부위 및 공유 코너의 중복 여부
- 방수 접합 상세와 서로 같은/다른 물리적 코킹선의 구분

이 목록을 매번 사용자에게 전부 묻는 것은 아니다. 도면·자료·기존 답변으로 먼저 채우고, 결과를 바꾸는 미정 사항만 묶어 질문한다.

## 원문 근거 요약

> 최대발주길이는 13미터고 남는길이는 잔재처리함

> 하지 만나는곳마다 1개씩사용함

> 3미터로 발주하고 30-50정도 겹치게시공함

> 300간격으로 두줄고정

> 판넬과 판넬 만나는부분 창호랑판넬만나는부분 후레싱양쪽측면등 비들어가는부위에 코킹들어가고 한통으로2.5미터정도시공함

## XCLIP 표시 범위의 구현 정책 — 2026-11-17

사용자의 “실제 보이는 영역 기준으로 읽고 물량 산출” 요청을 반영한다. 아래는 프로그램의 범위 처리 정책이며, 기존 제품·자재 수량 기준을 변경하거나 실제 잘린 위치에 새 시공 끝단이 있다고 가정하지 않는다.

XCLIP 표시 영역만 산출한다. 판넬·하지 기준점과 실제 외벽·창호 경계는 원본을 유지하고, 잘라낸 가상 경계에는 후레싱·코킹·끝단 보강을 추가하지 않는다. 표시된 판넬 조각의 외접 규격으로 발주하며 사선 절단 잔재를 포함한다.

후레싱 피스는 표시된 연속 구간에 기존 최대 간격·양끝 포함 산식을 적용한다. 물리적 설치 위치가 도면에 직접 지정된 경우를 별도로 자동 인식하는 기능은 아니다. 정책은 `config/common-rules.json`의 `implementationPolicies.xclipVisibility`, 계산 코드와 산출서에 동일하게 기록한다. 원래의 사용자 확정 수치와 규칙 ID는 유지한다.

## 열린 선 복원 시 중복 방지 정책 — 2026-11-17

복원한 닫힌 면의 개수는 판넬 장수와 다르다. 같은 출처·평면·역할의 인접 복원 면이 빈틈 없이 하나의 직사각형을 이루면 연속된 외벽/개구부 범위로 계산한다. 단순 내부 표시선에 새 외곽 후레싱이나 창호 측면 후레싱을 중복 생성하지 않는다. 실제 판넬 이음·별도 창호 접합부의 의미는 시공 상세와 조건으로 확정한다. 비정형 합집합·다른 Z 평면·끊어진 경계·가는 틈의 의미가 불명확하면 확정 수량을 발행하지 않는다. 기존 제작 길이·체결·코킹 수치 규칙은 변경하지 않았다.
